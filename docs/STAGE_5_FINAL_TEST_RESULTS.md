## Local performance measurements

The benchmark used in-process Flask requests, a disposable SQLite dataset with eight seeded briefs and two fixtures per adaptive service, three warmups and 25 timed requests per route. Times include Flask rendering and SQLite processing. They exclude network time, browser rendering and production traffic. Timings varied with host load, and the statement counts provide the direct evidence of the query optimization.

| Route | Final p50 | Final p95 | Median SELECTs before → after |
|---|---:|---:|---:|
| Home | 0.29 ms | 0.32 ms | 0 → 0 |
| Client dashboard | 2.41 ms | 3.89 ms | 7 → 3 |
| My Briefs | 3.24 ms | 4.59 ms | 6 → 3 |
| Adaptive wizard | 15.13 ms | 17.61 ms | 7 → 5 |
| Adaptive save-state | 5.02 ms | 6.23 ms | 4 → 2 |
| Adaptive client review | 7.93 ms | 9.22 ms | 7 → 5 |
| Notifications | 1.93 ms | 2.56 ms | 5 → 3 |
| Designer dashboard | 2.50 ms | 4.43 ms | 9 → 5 |
| Designer brief review | 5.15 ms | 6.20 ms | 10 → 7 |
| Administrator directory | 1.87 ms | 2.89 ms | 5 → 3 |

SQLite query-plan checks used the recipient/read index for unread notifications, the assigned-provider/status index for queue lookups, and the brief/revision uniqueness index for latest-submission lookups. The live read-only checks found zero submission actor/owner mismatches and zero approval reviewer/assignment mismatches. The live notification table was empty, so recipient and event checks used disposable workflow fixtures.

## Reproduction and readiness

- Run the Python suite with `.venv\Scripts\python -m unittest discover -s tests -v`.
- Run the four browser scripts listed under F05-11 separately from the project root with the same interpreter. They launch an isolated local server and Chrome.
- Run `.venv\Scripts\python tests/final_system_benchmark.py` to repeat the local measurements.
- The evidence supports a **local DBIT demonstration of the core client and designer workflows**. Production deployment, full recovery, complete accessibility conformance and compliance with unavailable approved documents remain outside that assessment.
