GOOD TO KNOW

Understanding Questionnaire Status

Active

An active questionnaire is available for clients to select when creating briefs.

Inactive

An inactive questionnaire is unavailable for starting new briefs but its existing records are preserved.

Questionnaire Versions

Changes to a questionnaire must not alter versions already used by submitted project briefs.
